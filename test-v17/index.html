Démonstration

Un jeu d'opérations inventées simule les données de ton budget : revenus, dépenses et charges fixes. Le système calcule une estimation prudente, sans accéder à tes informations réelles.

Clique sur « Analyser » pour alimenter le simulateur automatiquement.

⚙️ Scénario de test

Modifie un montant : toutes les prévisions et alertes s'actualisent immédiatement.

📈 Prévision prudente

La projection est calculée sur les dépenses futures saisies. Les revenus incertains ne sont pas inclus. Le bouton d'analyse utilise trois mois de données fictives pour estimer les dépenses restantes. Les hypothèses sont ajustables.
